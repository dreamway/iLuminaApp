# App功能分析与功能分区构思

这是一个集成了眼部健康检测和门店管理功能的Android平板应用，面向用户：
1. **美容顾问**：主要使用眼部检测相关功能，为顾客提供眼部健康检测服务

## 核心功能模块

### 1. 用户角色与权限管理 （所有角色可用）
- **登录系统**：支持不同美容顾问登录
- **权限控制**：根据角色显示不同功能模块
- **账号管理**：个人信息维护和账号切换

### 2. 门店活动展示、护理项目、护理案例展示及介绍（所有角色可用)
- **服务展示及详情**：展示所有服务项目,查看服务流程、适用人群和价格
- **服务案例**：展示服务前后对比效果

### 3. 眼部健康检测 （需登录后使用）
- **客户选择/创建**：通过电话号码快速查找或创建客户
- **问卷调查**：9题OSDI干眼问卷填写
- **图像采集**：引导用户完成眼周图像拍摄
- **AI分析**：分析眼周图像，生成评估结果
- **五维度评分**：疲劳度、浑浊度、脆弱度、松弛度、老化度
- **结果展示**：多维度展示检测结果，支持点击查看详情

### 4. 配置管理及系统管理 （需登录后使用）
- **客户档案**：管理客户基本信息
- **检测历史**：查看客户历次检测记录

## 用户角色与权限系统

### 美容顾问角色
- **可访问功能**：
  - 首页：查看门店活动、服务项目和服务案例
  - 检测：执行完整的眼部检测流程
  - 报告：查看近期检测的客户及客户检测报告
  - 我的：查看个人业绩、今日数据、访问门店管理、员工管理、修改系统设置等功能
- **权限限制**：
  - 只能查看自己的客户和业绩数据

## 眼部检测流程详解

眼部检测是系统的核心功能，完整流程如下：

1. **客户选择/创建**
   - 通过电话号码(合规要求，只查询前3后4）快速查找客户，若匹配出多个，可进一步在查询出来的列表中选择
   - 若为新客户，创建客户档案
   - 若为老客户，调用历史数据

2. **问卷调查**
   - 填写9题专业问卷
   - 评估眼睛异物感、不适感、电子设备使用等情况
   - 问卷结果作为AI分析的辅助数据

3. **图像采集**
   - 环境光检测，确保光线适合拍摄
   - 引导客户将眼部对准指示框
   - 拍摄清晰的眼周图像
   - 图像质量评估，确保分析准确性

4. **AI分析处理**
   - 图像预处理，提取关键特征
   - 结合问卷数据进行综合分析
   - 生成五维度评分和综合评分

5. **结果展示**
   - 显示综合评分和健康等级
   - 五维度雷达图展示（疲劳度、浑浊度、脆弱度、松弛度、老化度）
   - 支持点击各维度查看详情
   - 支持查看AI分析的图像对比和详细结果


## 交互设计特点

1. **多入口设计**
   - 检测功能可从多个入口进入（底部导航栏、首页热门服务、客户详情页）
   - 根据入口不同，可能跳过某些步骤（如已选择客户）

2. **深度交互**
   - 五维度雷达图支持点击交互，查看各维度详情
   - 检测结果支持多层级展示，从概览到详情
   - 图像对比功能，直观展示AI分析结果

3. **数据隐私保护**
   - 今日数据和客户信息集中在"我的"页面，减少信息泄露风险
   - 根据角色显示不同级别的数据，确保信息安全

4. **一致性体验**
   - 核心功能（如检测）对所有角色保持一致体验
   - 统一的设计语言和交互模式，降低学习成本
