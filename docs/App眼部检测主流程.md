# 美睛美科平板App眼部检测主流程

## 主要检测流程图

```mermaid
flowchart TD
    Start[开始] --> Auth[用户登录/认证]
    Auth --> Sync[数据同步]
    Sync --> A[开始检测]
    
    A --> B[客户选择/创建]
    B --> B1{是否为新客户?}
    B1 -->|是| B2[新建客户档案]
    B1 -->|否| B3[调用已有客户信息]
    B2 --> LocalSync[本地数据存储]
    LocalSync --> ServerSync[服务器同步]
    ServerSync --> C
    B3 --> C
    
    C[问卷调查] --> C1[填写9题问卷评估]
    C1 --> C2[问卷数据本地存储]
    C2 --> C3[问卷数据同步至服务器]
    C3 --> D[眼部图像采集]
    
    D --> D1[环境光检测]
    D1 --> D2[用户引导定位]
    D2 --> D3[图像采集]
    D3 --> D4[图像质量评估]
    D4 -->|质量不佳| D2
    D4 -->|质量合格| D5[图像本地存储]
    D5 --> D6[图像上传服务器]
    D6 --> E
    
    E[AI分析处理] --> E1[图像预处理]
    E1 --> E2[特征提取与分析]
    E2 --> E3[综合评分计算]
    E3 --> E4[评分结果本地存储]
    E4 --> E5[评分结果同步服务器]
    
    E5 --> F[结果展示]
    F --> F1[五维度雷达图展示]
    F1 --> F2[各维度详情查看]
    F2 --> F3[生成检测报告]
    F3 --> F4[报告本地存储]
    F4 --> F5[报告同步服务器]
    
    F5 --> G[方案推荐]
    G --> G1[基于AI分析推荐产品]
    G1 --> G2[显示产品详情]
    G2 --> H[结束检测]
```

## 离线功能支持

1. 本地数据存储
   - SQLite数据库
   - 本地文件系统（图片存储）
   - 本地缓存机制

2. 数据同步策略
   - 定时同步
   - 手动同步
   - 网络恢复自动同步
   - 冲突解决机制

3. 离线检测支持
   - 完整检测流程支持
   - 本地AI模型
   - 数据临时存储
   - 后续同步机制

## 系统权限要求

1. 必需权限
   - 相机权限
   - 存储权限
   - 网络权限

2. 可选权限
   - 位置信息
   - 设备信息

## 异常处理机制

1. 网络异常
   - 本地模式切换
   - 数据缓存
   - 重试机制

2. 设备异常
   - 相机异常处理
   - 存储空间不足提示
   - 电量不足提示

3. 服务器异常
   - 降级服务
   - 本地模式
   - 错误提示

## 数据安全

1. 本地数据
   - 数据加密存储
   - 敏感信息保护
   - 定期清理机制

2. 传输安全
   - HTTPS传输
   - 数据加密
   - Token认证

3. 权限管理
   - 用户角色权限
   - 数据访问控制
   - 操作审计
